# Procedencia del caso de muestra

Adaptado del phenopacket `PMID_7668832_Father.json`, cohorte GAA,
phenopacket-store release 0.1.27, curado por Monarch Initiative.
Referencia: Wokke et al., *Genotype-phenotype correlation in adult-onset acid
maltase deficiency*, Ann Neurol (1995), PMID:7668832, DOI:10.1002/ana.410380316.

URL exacta, versión y hash del JSON público en `pompe_case.json`.
Se incluyen únicamente los cinco hallazgos presentes/negados; no se copian
variantes genéticas, relaciones familiares ni identificadores de sujeto.
El nombre de archivo original sólo identifica la procedencia pública.
Narración ES/EN redactada para la demo, no cita ni transcripción de audio real.
